# Vita Vox — Building

Version **00.39**. This is the source tree as published in `vita_vox_v00.39_source.zip` (and in git). It contains the application sources, tests, scripts, fonts, LiveArea assets and this documentation. It does **not** contain a pre-built VPK, object files, or a pre-built FFmpeg.

## What is not in the source archive

| Excluded | Why |
|---|---|
| `third_party/ffmpeg/` | Cross-compiled LGPL FFmpeg prefix (headers and static libraries). It is generated by `scripts/build_ffmpeg.sh` and is gitignored. The full FFmpeg 9.0.2 source is downloaded at build time (see below), not vendored, so the archive stays small. |
| `build/`, `build-host/` | Object files, `eboot.bin`, and intermediate VPKs |
| `releases/*.vpk` | Built packages; they are gitignored. The source zip itself is written there after a docs commit, but is not part of the git tree |
| Host FFmpeg / libjpeg-turbo prefixes (`/tmp/ffmpeg-host`, `/tmp/jpeg-host`) | Optional, for host tests only |

To build a VPK you must have VitaSDK and then run `scripts/build_ffmpeg.sh` once.

## Toolchain

Requires [VitaSDK](https://vitasdk.org/) (`VITASDK` on your `PATH`). On a fresh machine (or after the SDK disappeared), install the pinned toolchain with:

```sh
./scripts/setup_toolchain.sh          # cmake 3.31.8, make, bzip2, VitaSDK + libs
./scripts/setup_toolchain.sh --archive  # also write /workspace/cache/vitasdk.tar.zst
export VITASDK=/usr/local/vitasdk
export PATH="$VITASDK/bin:/usr/local/bin:$PATH"
```

`setup_toolchain.sh` pins cmake 3.31.8, make 4.4.1, and a complete package database (the script’s comment names 20261115.68.1) so a lost `/usr/local/vitasdk` can be reproduced.

### FFmpeg (required for the VPK)

A decoder-only **LGPL** FFmpeg is cross-compiled into `third_party/ffmpeg/` (or another prefix you pass as the first argument):

```sh
./scripts/build_ffmpeg.sh
# optional: ./scripts/build_ffmpeg.sh /path/to/prefix
```

The script downloads **FFmpeg 9.0.2** from ffmpeg.org into `/tmp/ffmpeg-build` (override with `FFMPEG_SRC_ROOT` / `FFMPEG_VER`), checks the official VITABUILD sha256 (`8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e`), and configures a trimmed decoder/demuxer set with no GPL, no encoders, muxers or network, and no extra codec packages (no libmp3lame / libvorbis / libopus / libflac). Native decoders include AAC, ALAC, MP3, FLAC, Vorbis, Opus, WMA, APE, WavPack, TTA and PCM. Demuxers include mov (MP4/M4B), mp3, aac, flac, ogg, matroska, wav, aiff, asf, ape, wv, caf and tta.

CMake looks for `${CMAKE_SOURCE_DIR}/third_party/ffmpeg` (override with `-DFFMPEG_PREFIX=...`) and fails if `libavcodec.a` is missing.

## Building the VPK

```sh
mkdir -p build && cd build
cmake ..
make -j$(nproc)
```

The package is `build/vita_vox_v00.39.vpk` (TITLEID `VVOX00001`). A copy is also written to `releases/`. `param.sfo` `APP_VER` is `00.39`; the in-app About line and the log start line are `Vita Vox 00.39`.

There is **one version number** everywhere (since 00.31): About, the log start line, `param.sfo` `APP_VER`, `CMakeLists.txt` (`set(APP_VERSION "00.39")`), `Makefile.host`, the README, the commit message (`v00.39: ...`), and the VPK file name. Do not change only some of these. Every release build bumps the last two digits: 00.31, 00.32, … 00.99, then 01.00.

Optional: `cmake -DAUTOPILOT=ON` builds scripted input from `ux0:data/VitaVox/autopilot.txt` (never used for release VPKs).

The self is built `UNSAFE` with `ATTRIBUTE=0x88008` (keep running when deactivated, no system suspend) so a book can play in the background and through the power button.

## Host tests

The hardware-independent core builds on Linux/macOS with AddressSanitizer and UndefinedBehaviorSanitizer:

```sh
make -f Makefile.host test
```

This does **not** need FFmpeg or VitaSDK. Suites in `tests/main.c`:

`timeline`, `strutil`, `pathutil`, `probecache`, `policy` (including config load/save), `utils`, `groups`, `icons`, `libcache`, `tagart`, `thumbs`, `bookcache`, `series` (including per-series list/grid persistence), `audio_out`, `dbg`, `touch`, `libroot`, `mp3info`, `statusbar`, `hold` (SELECT short vs 2 s hold).

FFmpeg-backed tests (stream open, library host paths, lazy MP4, priority open, MP3-scan fallbacks, description tags):

```sh
make -f Makefile.host test-decode   # needs a host FFmpeg in /tmp/ffmpeg-host
```

`FFMPEG_HOST` defaults to `/tmp/ffmpeg-host` (a host build of the same 9.0.2 tree, not the Vita prefix).

JPEG thumbnail checks and the thumbnail benchmark use libjpeg-turbo on the host when it is installed at `JPEG_HOST` (default `/tmp/jpeg-host`, e.g. `cmake -DCMAKE_INSTALL_PREFIX=/tmp/jpeg-host -DENABLE_SHARED=OFF` in a libjpeg-turbo source tree). Without it they fall back to stb_image and skip the benchmark.

## LiveArea assets

Generated by `tools/make_art.py` (Pillow, Manrope in `assets/fonts/`). The Vita wants 8-bit indexed PNGs:

| File | Size | Notes |
|---|---|---|
| `sce_sys/icon0.png` | 128×128 | No alpha |
| `sce_sys/livearea/contents/bg.png` | 840×500 | No alpha. Text: “Vita Vox” / “Audiobook Player for PS VITA” |
| `sce_sys/livearea/contents/startup.png` | 280×158 | Alpha via a tRNS chunk (rounded corners) |
| `sce_sys/livearea/contents/template.xml` | — | `style="a1"`, `content-rev="5"` |
| `assets/logo.png` | 28×28 | In-app header: orange circle, dark headphones around an open book |

pngquant is used when it is on `PATH`; otherwise Pillow’s quantizer is used. Rebuild with `python3 tools/make_art.py` from the repository root. Font ink metrics for the UI are regenerated with `tools/gen_font_metrics.py` into `src/ui/font_metrics.h`.
